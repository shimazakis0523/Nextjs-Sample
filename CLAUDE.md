# Pull Requests

Pull request titles and descriptions for this repository MUST be written in
Japanese (日本語), regardless of the language used elsewhere in the
conversation. This applies to new PRs and to updates of an existing PR's
title/body.

# Source Code Comments

Comments in source code (`src/**`, config files such as
`playwright.config.ts`/`eslint.config.mjs`/`next.config.ts`, and any other
project code) for this repository MUST be written in Japanese (日本語).
This applies to new code and to edits of existing comments. Exception: a
tool-recognized magic/pragma comment whose exact text is meaningful to that
tool (e.g. Jest's `@jest-environment` docblock, `eslint-disable` directives)
MUST be left as-is — do not translate the directive itself, though you may
add a separate Japanese comment alongside it to explain why it's there.
